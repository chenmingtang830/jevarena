# JevArena

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User-approved: Next.js, TypeScript, Tailwind, shadcn/ui, Vercel hosting; Python batch research retained.

## Users and purpose
Developers, researchers and curious visitors compare Jev judgments with other models, discover failure boundaries, and contribute reproducible cases. Every battle includes Jev. BYOK users pay their provider; the site supplies no model credit.

## Confirmed workflows
Custom finite-choice judgment and answer-pair evaluation. Arena hides identities until voting; Compare selects an opponent. Quality precedes cost/latency reveal. Browser keys are tab-memory only; no accounts or key vault. Optional explicit-consent research intake uses a private Supabase schema and downloadable deletion receipts; it is deployment-gated until live acceptance checks pass. GitHub hosts separate public contributions and discussion; reviewed cases become public static pages. Public visitors can guess, inspect and share without keys.

## Evidence and boundaries
Existing Python harness and pinned downloads from three public sources. Small authorized transport canaries exist, not model-quality conclusions. Do not fabricate scores, community counts or model performance. Browser submissions are untrusted and remain separate from benchmark evidence. A voted preference is not correctness. New paid runs require specific authorization.

## Accessibility
English UI, arbitrary-language input, desktop and mobile layouts, keyboard access, visible focus, screen-reader labels and reduced motion.

## Delivery
User explicitly approved full implementation, multi-agent parallel work, and reviewed PR merges. Use the existing Vercel-provided `jevarena-lab.vercel.app` domain; no paid domain purchase. The user separately approved Supabase Pro and retained a 30-day private review window; this does not authorize unrelated purchases, paid WAF rules, or unlimited overages. Provisioning and release status must be verified separately from this product intent. Clean experimental workbench with equal-weight result columns.
