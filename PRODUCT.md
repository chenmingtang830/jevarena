# JevArena

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User-approved: Next.js, TypeScript, Tailwind, shadcn/ui, Vercel hosting; Python batch research retained.

## Users and purpose
Developers, researchers and curious visitors compare Jev judgments with other models, discover failure boundaries, and contribute reproducible cases. Every battle includes Jev. BYOK users pay their provider; the site supplies no model credit.

## Confirmed workflows
Custom finite-choice judgment and answer-pair evaluation. Arena hides identities until voting; Compare selects an opponent. Quality precedes cost/latency reveal. Browser keys are tab-memory only. No accounts or database. GitHub hosts contributions and discussion; reviewed cases become public static pages. Public visitors can guess, inspect and share without keys.

## Evidence and boundaries
Existing Python harness, pinned downloads from three public sources, 18 local tests. No live model results or paid canary authorized. Do not fabricate scores, community counts or model performance. Browser submissions are untrusted. A voted preference is not correctness.

## Accessibility
English UI, arbitrary-language input, desktop and mobile layouts, keyboard access, visible focus, screen-reader labels and reduced motion.

## Delivery
User explicitly approved full implementation and multi-agent parallel work. Prioritize reserving free jevarena.vercel.app; no paid domain or plan upgrades. Clean experimental workbench with equal-weight result columns.
