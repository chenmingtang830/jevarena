# TypeSafe reference, JevArena identity

Reference reviewed: [TypeSafe homepage](https://typesafe.ai/), 2026-09-19. This is visual inspiration, not an official TypeSafe design kit, asset license, partnership, or endorsement.

## Observed on the rendered source

The opening uses a vivid pink, pixel-textured sky, stark rectangular navigation labels, and a small desktop-window-like news panel. That panel pairs a dark title bar with monospace technical metadata. Large black type and white space separate editorial content from the illustrated opening.

## What belongs in this repository

| Source element | JevArena adaptation | Boundary |
| --- | --- | --- |
| Compact technical window labels | Compact section headers, stable version labels, monospace measurements | Explain real state, not decorative fake telemetry |
| Strong editorial type and clear boundaries | Existing Geist hierarchy, thin separators, readable text inputs | Preserve the working form and accessibility |
| Typed decisions as the visual subject | Equal X/Y judgments with explicit choice IDs | Never favor Jev visually before voting |
| Pink pixel atmosphere | Optional future community/share artwork direction | Not a form background; not yet adopted as production tokens |

The canonical current tokens remain in `web/app/globals.css`, with their semantics in `DESIGN.md` and `.impeccable/design.json`. These reference notes augment the existing system; they do not silently replace the live green workbench. A future visual PR should include paired desktop/mobile screenshots and a concrete account of which references it uses.

Do not copy TypeSafe's logo, wordmark, downloadable art, proprietary fonts, source CSS, benchmark graphics, or marketing claims. In particular, promotional accuracy/speed/cost claims do not become JevArena findings. Keep the independent-project notice. An eventual pink accent must be an original token tested for contrast and applied equally to both judges.

## Review checklist

- A screen's purpose (operate/read) determines density; inspiration does not outrank usability.
- Before-vote colors, loading state, typography and card size give both judges equal weight.
- Every copied reference is attributed; every shipped asset has clear reuse rights.
- No provider name, timing, cost, probability or explanation appears before the vote.
- Keyboard, reduced-motion and mobile result-focus flows survive visual changes.
- Owner approval and CI are required before these changes reach production.
